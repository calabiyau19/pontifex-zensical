## Welcome to My Documentation Hub

This is a working record of a homelab built one deliberate step at a time — Proxmox, self-hosted applications, Linux, and networking, documented as I go.

## How This Started

My Linux journey began with an old, dust-collecting laptop and a decision to actually commit this time, instead of dabbling the way I had with Slackware years earlier. What started as a shotgun approach — sticky notes, Google Docs, whatever tool was closest at hand — settled over time into something more deliberate: verify before you act, one command at a time, never guess.

## Why Zensical

This site ran on Jekyll for a long time, and that content is still the foundation of everything here. But Jekyll and Material for MkDocs have gone largely unmaintained, and Zensical — built by the same team behind Material for MkDocs — is where this documentation now lives. The migration itself, and the reasoning behind it, is documented like everything else on this site.

## The Range

"Homelab" ends up covering more ground than it sounds like. Media servers sit next to network monitoring tools, self-hosted finance trackers sit next to VM cloning scripts, and a Telegram install guide sits next to a full writeup of migrating this very site to a new platform. If it runs somewhere in this house and I had to figure it out, it's probably here.

## What You'll Find Here

- Step-by-step guides, written from real setups, not theory
- Troubleshooting notes from things that actually broke
- Infrastructure decisions, including the ones that got reversed
- A running project archive backing all of it, so the "why" behind a decision isn't lost once the task is done

This is still a work in progress — it always will be. But it's no longer a shotgun.
